Zoi Unfiltered API keys

Generate keys for your own applications that call Mallow Bot's hosted Zoi Unfiltered API. Keys are stored as hashes, and you can revoke them at any time. You can keep up to five active keys.

An active Premium subscription is required. If Premium expires or is revoked, its API keys stop working.

Using the API

Send requests to the Mallow Bot website API endpoint with your generated key as a Bearer token. This endpoint requires the hosted Unfiltered model to be configured by the bot owner.

Endpoint

POST /api/zoi-unfiltered

Example request

curl -X POST "https://mallowbot.kz.ci/api/zoi-unfiltered" \
  -H "Authorization: Bearer YOUR_MALLOW_ZOIU_KEY" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Hello, Zoi."}]}'

Never share your key in a public channel, repository, or client-side website. Revoke a key immediately if it leaks.
