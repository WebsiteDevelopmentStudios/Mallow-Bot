Need a hand?

Use these steps to narrow down dashboard or bot problems before reporting them.

Dashboard or login issue

  • Refresh after the Cloudflare Pages deployment completes.
  • Try a hard refresh with Ctrl + Shift + R.
  • Confirm you signed in to the Discord account that manages the server.
  • Check whether the page shows a clear error after saving.

Bot feature not working

  • Confirm Mallow is online and has the required channel/role permissions.
  • Check that the feature is enabled for that server.
  • Check the bot host logs for exceptions or missing configuration.
  • Include the command, server feature, and exact error when asking for help.

Community support

For community help, visit the Mallow Bot support community if one has been configured by the bot owner.
