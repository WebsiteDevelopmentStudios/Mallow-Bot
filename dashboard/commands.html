Command guide

Find your next command.

Use this guide to understand the common command groups. The exact commands available depend on the features enabled on your server and the bot version currently running.

Configure a server →

General

/help — show help, if registered.

/ping — check bot response, if registered.

/about — view bot information, if registered.

Economy

Look for balance, daily reward, work, and transfer commands if the economy feature is enabled.

Command names can vary by the bot build. Use Discord's / autocomplete to see commands actually registered.

Leveling

XP and level commands depend on the leveling module being enabled and deployed. Check Discord slash-command autocomplete for the current list.

Moderation and tickets

Moderation commands require appropriate Discord permissions. Ticket commands require the ticket handler and ticket feature to be enabled.

This guide intentionally does not claim commands are registered unless the running bot exposes them.
