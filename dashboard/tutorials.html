Getting started

Make Mallow yours.

Follow these quick guides to invite Mallow, configure your server, and get the features you want running.

Open server dashboard →

01 · Add Mallow

  1. Open Choose a server and sign in with Discord.
  2. Select a server where you have Manage Server permission.
  3. If Mallow is not installed, choose Invite Mallow and approve the requested permissions.
  4. Return to the server list and open its dashboard.

02 · Configure your server

  1. Pick a server from the left rail or server selector.
  2. Use Settings to configure the command prefix and general options.
  3. Use Messages to customize greeting text and message behavior.
  4. Save changes and check the status message for errors.

03 · Set up tickets

  1. Open Tickets in the dashboard.
  2. Enable tickets, then select a category and one or more support roles.
  3. Optionally select a transcript channel and customize the welcome message.
  4. Save your settings. Ticket commands/panel publishing require the bot service to support them.

04 · Economy and leveling

Use the Economy System tab to set virtual currency rewards and the Leveling System tab to tune XP ranges, cooldowns, and level-up announcements. These settings are server-specific.

If a setting saves but does not change bot behavior, the corresponding bot feature may still need to read that configuration.
