Mallow Bot — New in This Update

- Added `-mb purge <1-100>` as a text-command equivalent to `/purge`. Requires Manage Messages permission for the user and bot.
- Added `-mb ticket` to open a private support ticket when tickets are enabled in the Mallow dashboard.
- Added `-mb ticket-panel` to post the support-ticket panel. Requires Manage Server permission.
- Added `-mb ticket-close` to close a ticket, limited to the ticket creator or support staff.
- Added `-mb dm @member <message>` as a text-command equivalent to `/dm`. Requires Manage Messages permission and a configured DM log channel.
- Fixed slash-command syncing to remove guild-specific copies that caused duplicate commands. Run `/sync` or `-mb sync` in each affected server; Discord may take a few minutes to refresh.
