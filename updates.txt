NEW IN THIS UPDATE

MODERATION
• Added `-mb purge <1-100>` as a text-command equivalent to `/purge`. Requires Manage Messages permission for the user and bot.

SUPPORT TICKETS
• Added `-mb ticket` to open a private support ticket when tickets are enabled in the Mallow dashboard.
• Added `-mb ticket-panel` to post a ticket panel. Requires Manage Server permission.
• Added `-mb ticket-close` to close a ticket. Only the ticket creator or support staff can close it.

DIRECT MESSAGES
• Added `-mb dm @member <message>` as a text-command equivalent to `/dm`. Requires Manage Messages permission and a configured DM log channel.

SLASH COMMAND FIX
• Fixed `/sync` and `-mb sync` so they remove guild-specific command copies instead of duplicating global commands.
• Run the sync command in each server where duplicates remain. Discord may take a few minutes to refresh.
